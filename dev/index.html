    Strata¶

    Strata is a notebook your coding agent can drive, and everything it computes stays.

    An agent adds and runs cells through the strata CLI while the browser on the same session updates. Captured from a real run, not a mock-up.

    • Coding agent

      Hand a notebook to Claude Code and watch it build through MCP tools.

      Use a coding agent →

    • Web UI

      Write and run cells yourself, with rendered tables, plots and the DAG.

      Your first notebook →

    • Terminal

      Watch a notebook live from a second pane or an SSH session. Read-only.

      Terminal viewer →

    Install¶

    uv tool install "strata-notebook[mcp,tui]"
strata-notebook

    Then open http://localhost:8765. The mcp and tui extras are what strata agent and strata watch need. Plain pip install is not supported.

    docker compose up -d --build

    Then open http://localhost:8765.

    Or run the prebuilt image (linux/amd64), published with each release:

    docker run --rm -p 127.0.0.1:8765:8765 -v strata_state:/home/strata/.strata \
  ghcr.io/bearing-research/strata:0.11.0

    uv sync
cd frontend && npm ci && npm run build && cd ..
uv run strata-notebook

    Then open http://localhost:8765.

    See Install for full details.

    Why the work holds up¶

    Nothing runs twice. A cell's identity is its source, its inputs and its environment. The step an agent ran ten turns ago is a cache hit now, and an edit re-runs only the cells below it.

    Edit one cell in strata tutorial: only the cells that read it run again, and the cell above keeps what it saved. Captured from a real run, not a mock-up.

    No wiring to maintain. Strata reads each cell to find what it uses and what it defines, and shows which results an edit has left stale.

    Every result knows where it came from. Every output is a versioned artifact, so you can trace it back through what produced it.

    It reads like code in git. A notebook is one plain-text file per cell plus a TOML manifest. Outputs and caches stay in a gitignored folder.

    There is more on the Features page, and Strata also works as a library.

    Strata is pre-1.0, so the API may change between 0.x minors; pin to a minor if you need stability.
